2.3.3.3.38. NXauger_line¶

Status:

base class (contribution), extends NXobject

Description:

An Auger line. It arises from the non-radiative decay of an atom with a ...

An Auger line. It arises from the non-radiative decay of an atom with a core hole: an electron from a higher level fills the hole and another electron, the Auger electron, is ejected, with a kinetic energy characteristic of the atom.

Symbols:

No symbol table

Groups cited:

NXelement

Structure:

name: (optional) NX_CHAR

The Auger line name using either the notation ``INITIAL-FINAL1FINAL2`` ...

The Auger line name using either the notation INITIAL-FINAL1FINAL2 for a specific line or INITIAL-TOTAL (e.g. K-TOTAL) for the sum over all Auger lines originating from a given initial edge.

The initial edge is one of: K, L1-L3, M1-M5. The two final edges range from L through Q.
