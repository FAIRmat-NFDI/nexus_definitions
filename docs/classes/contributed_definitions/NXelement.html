2.3.3.3.51. NXelement¶

Status:

base class (contribution), extends NXobject

Description:

A chemical element of the periodic table. It is identified by its atomic number, as a species and not as a specific isotope.

Symbols:

No symbol table

Groups cited:

none

Structure:

symbol: (optional) NX_CHAR
