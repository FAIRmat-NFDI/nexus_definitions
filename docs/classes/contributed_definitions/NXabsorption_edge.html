2.3.3.3.10. NXabsorption_edge¶

Status:

base class (contribution), extends NXobject

Description:

An absorption edge is a sharp discontinuity in the X-ray absorption spectrum ...

An absorption edge is a sharp discontinuity in the X-ray absorption spectrum of an atom that occurs when the incident photon energy reaches the threshold energy for exciting the atom from its neutral ground state to a core-vacancy state.

No symbol table
