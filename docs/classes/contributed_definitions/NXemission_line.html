2.3.3.3.53. NXemission_line¶

Status:

base class (contribution), extends NXobject

Description:

An emission line. It arises from the radiative decay of an atom with a ...

An emission line. It arises from the radiative decay of an atom with a core hole: an electron from a higher level fills the hole and a photon is emitted, with an energy characteristic of the atom.

Symbols:

No symbol table

Groups cited:

NXelement

Structure:

name: (optional) NX_CHAR

The emission line name using either the `IUPAC notation`_, i.e. initial and fi ...

The emission line name using either the IUPAC notation, i.e. initial and final edge separated by a hyphen (e.g. K-L3), or the Latinized Siegbahn notation (e.g. Ka1).
